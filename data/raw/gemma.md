# Gemma 3

## Overview

Gemma 3 is a family of open-weight models developed by Google DeepMind. These models are built using research and technology related to Google's Gemini models.

Gemma 3 supports both text and image inputs and generates text outputs. It offers multiple model sizes, multilingual capabilities covering more than 140 languages, and a context window of up to 128K tokens for supported variants.

## Applications

Gemma 3 can be used for question answering, text summarization, reasoning, and image understanding. For example, a developer can build an application that receives an image and a written question, then generates a response based on the provided information.

Its different model sizes also provide flexibility when selecting a model for a particular hardware environment.

## Limitations

Gemma 3 capabilities depend on the selected model variant. Developers should not assume that every checkpoint supports identical multimodal features or resource requirements.

Image understanding also introduces additional processing requirements compared with text-only applications. Selecting a suitable model size and testing image-related tasks are important before deployment.
