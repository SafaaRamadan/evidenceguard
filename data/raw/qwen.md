# Qwen3

## Overview

Qwen3 is a family of large language models developed by the Qwen team at Alibaba Cloud. It includes dense and Mixture-of-Experts (MoE) models with different parameter sizes, ranging from smaller models to much larger architectures.

One important feature of Qwen3 is its ability to operate in two modes: thinking mode and non-thinking mode. Thinking mode is intended for more complex tasks, while non-thinking mode focuses on providing efficient responses for general-purpose conversations.

## Applications

Qwen3 can be used for mathematical problem solving, programming assistance, multilingual conversations, logical reasoning, and general text generation. It also supports tool usage and can be integrated into applications using frameworks such as Transformers, vLLM, and Ollama.

## Limitations

The two operating modes have different purposes. Thinking mode can generate longer reasoning outputs, which may increase response time and computational requirements. Non-thinking mode may be more suitable for straightforward questions but is not necessarily the best choice for every complex reasoning task.

Choosing the correct mode and model size is important when developing applications with Qwen3.
